# Knowledge Base Quick Start - Copy to Cursor

**Copy this entire block to Cursor when starting a new project:**

---

```
I want to set up a living knowledge base system for this project. Please:

1. Copy `/Users/geekio/Dev/Foundational Dev Docs/KNOWLEDGE_BASE_TEMPLATE.md` to `KNOWLEDGE_BASE.md` in this project root

2. Copy `/Users/geekio/Dev/Foundational Dev Docs/SHARED_FLUTTER_PATTERNS.md` to `SHARED_FLUTTER_PATTERNS.md` in this project root (for reference)

3. Create `KNOWLEDGE_BASE_UPDATE_CHECKLIST.md` with this content:
   - Quick checklist for updating knowledge base before commits
   - What counts as "significant work"
   - Update format guidelines
   - Reminder that updates are mandatory

4. Create `KNOWLEDGE_BASE_ARCHIVE.md` (empty for now, will be used when main file grows too large)

5. Create `KNOWLEDGE_BASE_QUICK_REF.md` with sections for:
   - Decision matrix
   - Quick fixes
   - Common patterns
   - Never do these
   - Always do these
   - Debugging checklist

6. Create `.cursorrules` file with:
   - Knowledge base maintenance rules (CRITICAL section requiring updates before commits)
   - Project-specific code style rules (customize as needed)
   - Testing guidelines (customize as needed)

7. Customize `KNOWLEDGE_BASE.md`:
   - Replace `[Project Name]` with the actual project name
   - Update "Last Updated" date to today's date (format: YYYY-MM-DD)
   - Add initial architecture description in "Architecture Evolution" section
   - Add any initial decisions or learnings

Reference the detailed setup guide at `/Users/geekio/Dev/Foundational Dev Docs/KNOWLEDGE_BASE_SETUP_GUIDE.md` for complete instructions and templates.
```
